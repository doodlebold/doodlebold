Doodlebold third-party notices
==============================

Doodlebold itself is released under the MIT licence (see LICENSE). It uses the
software listed below. Each entry says what it is, how it is licensed and where
its source code is. The full licence texts are in the third_party/ folder of the
source, and in share/licenses/doodlebold of an installed package.

Entries marked "AppImage only" are inside the Linux AppImage and are not in the
Windows zip or the Fedora RPM (the RPM uses the libraries of the system it is
installed on).


Qt 6
----

What:     The application framework. Doodlebold uses the Qt modules Core, Gui,
          Widgets, OpenGL, OpenGLWidgets, Svg, Network and DBus, Multimedia where
          the build has it (an animation's sound clips), and
          the Qt Wayland platform plugins (the Windows and AppImage packages
          also contain the Qt plugins those modules need).
Version:  6.8.3 in the Windows zip and the AppImage. The Fedora RPM uses
          Fedora's own Qt.
Licence:  GNU Lesser General Public License version 3 (LGPLv3), with parts under
          other licences (see "Code bundled inside Qt" below).
          Texts: third_party/LGPL-3.0.txt, third_party/GPL-3.0.txt
Source:   https://download.qt.io/archive/qt/6.8/6.8.3/submodules/
          Project: https://www.qt.io/

The Qt libraries are linked dynamically (as .dll files on Windows and .so files
on Linux). You can replace them with your own build of the same Qt version:
swap the files in the Windows zip's bin/ folder, or unpack the AppImage with
--appimage-extract, replace the libraries and plugins in it, and run it.

Timelapse export uses an FFmpeg program that you install yourself; Doodlebold
runs it as a separate program and does not link it.

Wayland protocol code
---------------------

What:     Doodlebold's Linux pen cursor and background blur use client code
          that wayland-scanner generates from the Wayland protocol XML files
          (tablet-v2, cursor-shape-v1, ext-background-effect-v1). The generated
          code is compiled into the program.
Licence:  MIT-style licences of the wayland-protocols project and of the
          individual protocol files.
Source:   https://gitlab.freedesktop.org/wayland/wayland-protocols
          (the AppImage is built with version 1.49)

Linux libraries bundled in the AppImage (AppImage only)
-------------------------------------------------------

The AppImage contains copies of the shared libraries that Doodlebold and Qt
need and that Ubuntu 22.04 (the system the AppImage is built on) provides. The
exact list depends on the build; unpack the AppImage with --appimage-extract and
look in usr/lib to see it. It includes libraries such as:

    glib, pulseaudio (libpulse), libsndfile, systemd (libsystemd), libgcrypt,
    libgpg-error, and the libraries they depend on.

Most of these are licensed under the GNU Lesser General Public License version
2.1 or later (LGPLv2.1+); some are under other licences, for example MIT or
BSD. Each one keeps its own licence. LGPL text: third_party/LGPL-2.1.txt

You can replace any of these libraries with a build of your own, because they
are separate files inside the AppImage.

Source: the source packages of Ubuntu 22.04 ("jammy"), at
          https://launchpad.net/ubuntu/jammy
        Search there for the package name (for example "glib2.0",
        "pulseaudio", "libsndfile", "systemd", "libgcrypt20") to find its
        source and its copyright file.
